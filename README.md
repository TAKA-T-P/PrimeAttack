# 素数スピード (Prime Number Speed)

中央に出た合成数カードを、自分の素数カードで素因数分解していくスピード系カードゲームです。ブラウザだけで動作する静的Webアプリで、`index.html` 1ファイルにHTML/CSS/JavaScriptがすべて含まれています。ビルドやサーバーは不要で、ファイルを開くかどこか静的ホスティングに置くだけで遊べます。

## 遊び方（起動方法）

`index.html` をブラウザで直接開くだけです（`file://` でも動作します）。GitHub Pages 等の静的ホスティングでも配信可能です。

## モード

- **1人用（CPU対戦）**: プレイヤー(1P) vs CPU(2P)。CPUの強さをレベル1〜5・MAXの6段階から選択できます。
- **2人用（1台対戦）**: 1台のスマホ/タブレット/PCを2人で向かい合わせて使う対戦モード。通信対戦は非対応です。

タイトル画面の各設定はすべてボタン形式です（ラジオボタンやプルダウン、チェックボックスは使用していません）。

- **モード選択**: 「CPU対戦」「2人対戦」ボタンを1行に配置（単一選択）
- **CPU強さ**: 「1」「2」「3」「4」「5」「MAX」ボタンを1行に配置（単一選択、1人用のときのみ表示）
- **出題レベル**: 「1」「2」「3」「4」ボタンを1行に配置。押すたびにON/OFFが切り替わる複数選択式（デフォルトは1・2がON）
- **サウンド**: 画面右上のスピーカーアイコンのボタンでON/OFFを切り替え

出題レベルは1つ以上選択しないとスタートできません。設定内容は `localStorage` に保存され、次回起動時に復元されます（対戦成績などの保存は行いません）。

## ヘルプ

タイトル画面左上の「？」ボタンから、ゲームの基本ルールを確認できるヘルプ画面を開けます。素数カードの出し方、お手つき、パス、ターン終了、勝利条件、モードの違いなど、遊ぶために必要な最小限の内容のみを掲載しており、CPUの反応速度やお手つき率といった内部仕様は載せていません。ヘルプ画面を開いても、選択中のモード・CPU強さ・出題レベル・サウンド設定は変更されません。

## ゲームの基本ルール

1. 選択した出題レベルの合成数カードをすべて合わせてシャッフルし、山札にします。
2. 各プレイヤーは自分専用の素数カード山札（後述の枚数）を持ち、そこから5枚を手札として持ちます。
3. 画面中央に合成数カード（例: `28`）が1枚表示されます。
4. 手札の素数カード（2・3・5・7・11のいずれか）が、その合成数の**まだ使われていない素因数**であれば「正解」として場に出せます（例: `28 = 2×2×7` なら、2を2回・7を1回まで出せます）。
5. 出したカードは消費され、1秒後に自分の山札から新しいカードが同じ位置に補充されます（下記アニメーション参照）。
6. 合成数の素因数をすべて出し切る、または両者とも出せるカードがなくなると、そのラウンドは終了します（詳細は「ラウンド終了の流れ」）。
7. 自分の素数山札を全部引き切った（=山札の最後に仕込まれた「終了カード」を引いた）プレイヤーがその時点で**勝利**し、ゲームが終了します。

### 素数カードの初期枚数

| 素数 | レベル1・2のみ選択時 | レベル3または4を含む場合 |
|---|---:|---:|
| 2 | 6 | 6 |
| 3 | 5 | 5 |
| 5 | 4 | 4 |
| 7 | 4 | 4 |
| 11 | 0（出題されないため配られない） | 4 |

上記に「終了カード」1枚を加えたものが各プレイヤーの山札です（先頭5枚が初期手札、残りが引き札）。終了カードはシャッフル対象外で、必ず山札の一番下に固定されます。

### 出題レベルの合成数カード

| レベル | 色 | 枚数 |
|---|---|---:|
| レベル1 | 緑 | 18枚 |
| レベル2 | 青 | 14枚 |
| レベル3 | オレンジ | 20枚 |
| レベル4 | 赤 | 20枚 |

選択したレベルのカードをすべて合わせて1つの山札としてシャッフルします。山札が尽きたら、これまでに使用済みのカードを再シャッフルして山札として再利用します（直前と同じ数字が連続しないよう簡易的に調整）。

### 「先に出された」の救済ルール

自分が出そうとした素数を、直前1秒以内に相手（またはCPU）がすでに出していた場合は、お手つき扱いにはなりません。「この数は先に出された!」と表示され、カードは消費されず、他のカードは引き続き出せます。このときカードは画面中央方向へ0.3秒でスライドし、0.3秒かけて元の位置へ戻るアニメーションが再生されます。

### お手つき

上記の救済条件に当てはまらない誤ったカードを出すと「お手つき」になります。

- カードは消費されず手札に残ります（赤く0.35秒シェイクします）
- そのプレイヤー側の手札の上に「お手つき！」の大きな赤い警告が約0.9秒表示されます
- ステータス欄には「お手つき! 次のカードまで待とう」と表示され続けます
- そのプレイヤーは**次のラウンドが始まるまで**カードを一切出せなくなります

### パス（旧: 10カウント宣言）ボタン

ゲーム中いつでも「パス」ボタンを押すと、10秒カウントダウンが始まります（役割は元の「10カウント宣言」から変わっていません、ボタンの表示テキストのみ変更）。

- カウント中、宣言した側は新しい合成数カードが出るまで一切カードを出せません
- 相手側は通常通りプレイを続けられます
- 5・4・3・2・1で効果音が鳴ります（1のときはやや強めの音）
- カウントが0になると強制的にそのラウンドが終了します
- 合成数が完全に解かれる、または両者とも出せるカードがなくなった場合は、カウントを待たずラウンドが終了します
- 一度パスが宣言されると、そのラウンド中は両者ともパスボタンが無効化されます

## ラウンド終了の流れ

以下のいずれかの条件を満たすとラウンド終了処理が始まります。

1. 合成数の必要な素因数をすべて出し切った
2. 両プレイヤーとも、現在の手札で出せる有効なカードがない（お手つきロック中も含む）
3. パスの10カウントが0になった

条件を満たした瞬間に入力はロックされますが、**1.5秒後**に画面中央へ「ターン終了！」の表示が現れます（即座には表示されません）。この演出は水色半透明のカードとして表示され、画面全体を暗くすることはありません。カード内には完了した合成数の素因数分解（例: `28=2×2×7`）が表示され、「次へ」ボタンを押すまで次のラウンドは始まりません。2人用モードでは、このカード全体が90度回転して表示されます（合成数表示と同じ向き）。

「次へ」を押すと、場の合成数カード・使用済みカード表示・お手つき/パスの状態がリセットされ、新しい合成数カードが表示されて次のラウンドが始まります。

## 画面レイアウト

- 画面上段: 2P（またはCPU）側 — 手札、山札残り枚数、パスボタン
- 画面中央: 合成数カード + 両者の使用済み素数カード（合成数カードの左右に表示）
- 画面下段: 1P側 — 手札、山札残り枚数、パスボタン
- 右上: ポーズボタン（プレイ中のみ表示）

CPU側の手札は常に180度回転して表示されます（1人用モードでも）。2人用モードでは、上段（2P）の手札・山札残り枚数・パスボタン一式がまとめて180度回転し、下段（1P）から見た並び順（パス → 山札残り → 手札 の順で画面端から中央へ向かう並び）と一致するように配置されています。合成数カード周辺の表示（合成数カード・使用済みカード）は、2人用モードのときだけ右に90度回転し、かつ画面右寄りに表示されます（上下どちらから見ても公平に読みにくくするため）。

手札の各カードは、素数を出した位置がそのまま空きスロット（点線の枠）になり、1秒後に新しいカードがその同じ位置へ下（または回転先の対応する方向）からスライドインして補充されます。左詰めにはなりません。

山札残り枚数は「山札 残りN枚」の形式で表示され、数字部分のみ太字・2倍サイズで表示されます。残り枚数がちょうど3枚になった瞬間、手札のすぐ上に「残り3枚！」という半透明の警告が大きく表示され、1.2秒かけてフェードアウトします。

使用済み素数カード（そのラウンド中に出されたカード）は合成数カードの左右に小さな丸チップとして残され、1Pが出したものは白地に黒文字、2P/CPUが出したものは濃色地に薄い文字で表示されます。ラウンドが終わると消去されます。

## ゲーム開始・演出

スタートボタンを押すと、タイトル画面が非表示になります。1人用（CPU対戦）の場合はここでCPUキャラクターが登場し（詳細は「CPUキャラクター」参照）、約1.8秒表示された後、山札の準備が完了した「3」「2」「1」「START!」のカウントダウンが画面中央に表示されます（それぞれ効果音付き）。カウントダウン終了後に最初の合成数カードが表示され、対戦が始まります。2人用モードではキャラクター演出はなく、従来通りカウントダウンから始まります。

## CPU仕様

CPUは以下の情報のみを使って行動します（プレイヤーの手札の中身は使用しません）。

- 現在の合成数
- まだ場に出ていない素因数の残り数
- 自分の手札5枚

行動タイミングごとに、難易度に応じた反応時間（下表）だけ待ってからカードを1枚出します。お手つき率に応じてランダムに正解／わざと無効カードを選び、無効カードが手札にない場合は正解カードを出します。

| 強さ | 反応時間 | お手つき率 |
|---|---|---:|
| レベル1 | 3200〜5200ms | 22% |
| レベル2 | 2400〜4000ms | 15% |
| レベル3 | 1700〜3000ms | 8% |
| レベル4 | 1200〜2200ms | 4% |
| レベル5 | 800〜1500ms | 1% |
| MAX | 440〜900ms | 0%（お手つきしない） |

CPUはゲーム終了後（GAME_OVER）や、ラウンド終了演出中・お手つきロック中はカードを出しません。CPUの10カウント宣言（パス）はv1.0では未実装です。

## CPUキャラクター

1人用（CPU対戦）モードでは、選択したCPU強さごとに固有の敵キャラクターが登場します。反応速度やお手つき率などCPU自体の強さは変更されず、演出のみの追加です。2人用モードではキャラクター関連の表示は一切行われません。

| 強さ | キャラクター |
|---|---|
| レベル1 | 🐥 ピヨファクター |
| レベル2 | 🐺 プライムウルフ |
| レベル3 | 🥷 素数忍者シノビ |
| レベル4 | 🧙 ファクター魔導士 |
| レベル5 | 🐉 プライムドラゴン |
| MAX | 🤖 PRIME-X |

- **ゲーム開始時**: スタート直後、カウントダウンの前にキャラクターが絵文字・名前・セリフとともに登場します（約1.8秒間）。
- **ターン終了時**: 「ターン終了！」カード内にキャラクターが表示され、戦況に応じたセリフを話します。戦況は「1Pが正式に場に出した素数カードの累計枚数」と「CPUが正式に場に出した素数カードの累計枚数」の差で7段階（CPU大幅リード〜プレイヤー大幅リード）に判定されます（お手つきや「先に出された」救済では枚数は加算されません）。
- **ゲーム終了時**: 結果画面に、勝敗に応じたセリフとともにキャラクターが表示されます。
- 累計枚数は「もう一度」で0にリセットされます。タイトルへ戻って別のCPU強さを選ぶと、次の対戦では新しいキャラクターが登場します。

## ポーズ機能

プレイ中に右上の「ポーズ」ボタンを押すと、「タイトル画面へ戻りますか？」の確認ダイアログが表示されます。

- 「はい」: すべてのタイマーを停止し、タイトル画面に戻ります（設定内容は保持されます）
- 「いいえ」: 元の対戦状態（CPUの行動タイマー、パスのカウントダウンを含む）に戻ります

## 結果画面

いずれかのプレイヤーの素数山札が尽きる（終了カードを引く）とゲーム終了です。

- 1人用: 「勝ち！」または「負け…」
- 2人用: 「1P勝ち」または「2P勝ち」

勝敗表示の下には「出したカードの枚数」として、両者が正式に場に出した素数カードの累計枚数（例: 「1P：13枚　CPU：10枚」）が表示されます。

結果画面には以下のボタンがあります。

- **次の相手と戦う**（1人用でプレイヤーが勝利し、かつCPU強さがレベル1〜5のときのみ表示）: 1段階強いCPU（次のキャラクター）と続けて対戦します。MAXに勝利した場合や敗北時、2人用では表示されません
- **もう一度**: 同じ設定（モード・CPU強さ・出題レベル・サウンド設定）で山札を再シャッフルし、再戦します
- **タイトルへ**: タイトル画面に戻ります（設定は画面に残ります）

## サウンド

外部音源は使用せず、Web Audio API で単純な電子音を都度生成しています（カウントダウン、正解、お手つき、先出されメッセージ、ラウンド終了、パスの残りカウント、勝敗など）。ブラウザの自動再生制限対策として、AudioContextはスタートボタン押下時に初期化されます。

## 技術情報

- フレームワーク・ビルドツールなし。`index.html` 単体で完結する静的HTML/CSS/JavaScript
- 状態管理は素朴なJavaScriptオブジェクト（`state`）と、状態変更後に全体を再描画する `render()` 関数のみで構成
- レスポンシブ対応: `clamp()`、`100dvh`、`env(safe-area-inset-*)` などを使用し、スマートフォン縦画面を基準に、タブレット/PCでも表示が崩れないようにしています
- `localStorage` にモード・CPU強さ・出題レベル・サウンド設定のみを保存（対戦成績等は保存しません）

## v1.0で実装していない機能

- 通信対戦・オンラインランキング
- ユーザー登録・ログイン
- 対戦成績の保存
- CPU自身による10カウント宣言
